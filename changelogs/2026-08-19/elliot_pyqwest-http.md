- Use the same pyqwest client for generated ConnectRPC calls, scaling-group endpoint requests, and signed volume downloads, removing the SDK's direct httpx dependency. `ScalingGroup.call()` now returns an SDK-owned structural `HTTPResponse[bytes]` protocol, which pyqwest responses implement without a wrapper; callers should use `response.status` instead of `response.status_code` and consume `response.content` directly.
