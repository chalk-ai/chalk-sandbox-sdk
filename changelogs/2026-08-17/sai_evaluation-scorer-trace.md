- Add `chalkcompute.Trace`, the session-scoped telemetry an evaluation scorer reads for the task invocation it is scoring: declare a scorer argument as `trace: chalkcompute.Trace` and call `trace.get_spans()`, `trace.summary()`, or `trace.traces()`. It is named `Trace` for what a scorer means by "the trace" — the whole evaluated unit of work — but holds an agent *session* id, because a multi-turn agent emits one OpenTelemetry trace per turn and only a session id groups siblings. The id travels as `large_utf8` exactly as `str` would, so `trace: str` plus `Trace.from_id(...)` is equivalent. `get_spans()` waits for span ingest to settle by default and raises `TimeoutError` rather than returning a knowingly partial list, since a silently undercounted cost sum reads as a real score; `Span.attribute_float()` / `attribute_int()` parse the string-typed span attributes that summing directly would concatenate.
- Group a call's spans into the caller's session automatically: a `x-chalk-session-id` request header — what Chalk sends from `catalog_call(..., metadata => {'x-chalk-session-id': s})` — now enters the row's OpenTelemetry context, and a tracer-provider span processor stamps `session.id` onto every span started there, including spans from LLM instrumentation this SDK never sees. The id also rides outbound calls as W3C `baggage`, so a nested compute function's spans join the same session.
- An Arrow-backed class stays Arrow-backed under `Optional` and `Annotated`: `trace: Trace | None` now produces a nullable column of the class's own Arrow type and still decodes to an instance, instead of emitting a non-nullable column or failing schema conversion.
- The strip-mode deploy guard now inspects parameter and return *annotations*, not only function bodies. An annotation such as `trace: cc.Trace` fails at deploy with an actionable message rather than an opaque container-side `NameError` from the worker shim's `typing.get_type_hints` call.
- Request the monitoring-read permission on a deployed function's service-auth token, which every `chalk.server.v1.TraceService` RPC requires.
