- Add `chalkcompute.Rubric` and `chalkcompute.Criterion`, and a `rubric=` argument to `@chalkcompute.function`. A scorer declares the criteria it grades on; the declaration travels with the function version, and each result's criteria are validated against it and recorded with the row under `metadata["criteria"]`. The score is unchanged: it is still what the scorer returns, on the same wire shape every deployed server already reads.
- A scorer that declares a rubric and returns no criteria, or grades outside a criterion's scale, fails the row rather than averaging in as though it had graded; one that declares a rubric in strip mode fails at decoration, where the deployed image would have no `chalkcompute` to encode with.
