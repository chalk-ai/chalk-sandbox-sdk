- Add `chalkcompute.Rubric` and `chalkcompute.Criterion`, and a `rubric=` argument to `@chalkcompute.function`. A scorer declares the criteria it grades on; each becomes a field of its `EvaluationScorerResult` and a column of the evaluation's result dataset, so a criterion is aggregated and compared like the scorer's own score instead of being a number whose origin is unrecoverable. The score itself is unchanged: it is still what the scorer returns, and a scorer without a rubric still returns a plain number. Each criterion's scale and description travel with the deployed function version as Arrow field metadata.
- `Rubric.result(score, criteria, reason=...)` validates that the grades are exactly the declared criteria and within their scales. A scorer that declares a rubric and returns no criteria fails the row rather than averaging in as though it had graded, and one that declares a rubric in strip mode fails at decoration, where the deployed image would have no `chalkcompute` to encode with.
