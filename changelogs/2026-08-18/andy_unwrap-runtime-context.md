- Fix `chalkcompute.get_call_context()` returning the runtime's context envelope instead of the request's headers. `chalk_remote_call` hands the handler `{"function_name": ..., "peer": ..., "metadata": {<headers>}}`, so every header sat one level below where the accessor looked: `get_call_context().get("x-chalk-session-id")` was always `None`, and with it the automatic OpenTelemetry session grouping that a caller's `catalog_call(..., metadata => {'x-chalk-session-id': s})` is supposed to trigger. The headers are now unwrapped out of the envelope, and a flat mapping is still taken as the headers themselves.
