- Add `tracing=` to `Sandbox`, `SandboxClient.create`, `Container`, and `ScalingGroup`: `True` traces every request inside the workload, `TracingPolicy(sample_rate=...)` sets the root sample rate, and `False` turns tracing off, via the standard `OTEL_TRACES_SAMPLER` variables the platform's default sampler defers to. Sandbox RPCs now carry the caller's W3C trace context, each `exec`/`execute_python` hands it to the process as `TRACEPARENT`, and `chalkcompute` inside the sandbox adopts it, so a script's spans join the caller's trace.
